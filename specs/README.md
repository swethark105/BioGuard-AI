# Test plans

The Playwright **planner** agent saves its test plans here as Markdown files
(for example `specs/sample-overview.md`). The **generator** agent reads a plan
from this folder and writes the matching tests into `tests/agents/`.

Plans are drafts. Review and edit them before you ask the generator to turn
them into tests. See [docs/PLAYWRIGHT-AGENTS.md](../docs/PLAYWRIGHT-AGENTS.md).
